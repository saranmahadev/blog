The short version. Most retrieval projects need the same four things: a place to put vectors, a way to filter them, a way to update them safely, and a stable API.

The problem

I have now built the same ingestion and search plumbing three times. Each copy was a little better and a little more tied to its project.

The best API is the one you can describe in a single paragraph.
