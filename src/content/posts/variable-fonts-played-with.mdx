<Statement>One font file can be **many typefaces**. The trick is the *axes*.</Statement>

A variable font stores a range, not a single style. Instead of separate files for light, regular and bold, one file carries a weight axis you can set to any value in between. Some fonts add more: width, optical size, even softness.

<CurvedText text="Drag the sliders" shape="arc" />

## Try it

Pick a typeface, then move the axes. The CSS underneath updates as you go, ready to copy.
